# AI Chatbot Web App

A simple AI Chatbot Web Application built using React.

## Features

- Clean and responsive user interface
- Chat-style conversation window
- User message input
- Bot response display
- Beginner-friendly React project structure

## Technologies Used

- React
- JavaScript
- HTML5
- CSS3

## Installation

1. Clone the repository:

```bash
git clone https://github.com/ramlahht12-blip/ai-chatbot.git
```

2. Navigate to the project folder:

```bash
cd ai-chatbot
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```
